What this battery does

The Strategic Interpretation Battery is Call 7 — the client-facing strategy layer that sits above the three analytical batteries (Epistemic Motion, Forensic Analysis, Semantic Content). This is the Opposition View — the same instrument run with the defense's declared bias (Shell USA, Inc. and Shell Chemical, L.P.) rather than Judd's. The purpose is to understand how the same exchange looks from the other side of the table: what the defense would use, what they would fear, and how they would rank the analytical calls.

Because these files were generated with Shell as the declared client, the model's internal scores are Shell-centric: client_value = Shell's gain, opposition_value = Jasso's gain. These scores are swapped on display so that every SI document — prosecution and opposition alike — reads the same way: Client Value always means Jasso's gain, Opposition Value always means Shell's gain.
